Zihin · Arşivci Sincap · İris Moru

Windows
  windows/app.ico — 16, 24, 32, 48, 64, 128 ve 256 px.

macOS
  mac/app.icns — çok çözünürlüklü uygulama simgesi.

Web
  web/favicon.ico, web/favicon-16.png ve web/favicon-32.png — tarayıcı simgeleri.
  web/apple-touch-icon.png — 180 px ana ekran simgesi.
  web/icon-192.png, web/icon-512.png ve web/maskable-icon-512.png — PWA simgeleri.
  web/site.webmanifest — simgelere göreli yollarla başvuran web manifesti.
  web/head-snippet.html — aynı konumdaki web dosyalarına ait HTML bağlantıları.

PNG
  png/ — 16, 20, 24, 32, 40, 48, 64, 96, 128, 180, 192, 256, 512 ve 1024 px.
  master-1024.png — 1024 × 1024 px RGBA ana simge.
  export-preview.png — seçili boyutların gerçek piksel ölçülerinde karşılaştırması.
  metadata.json — kaynak, renk ve dosya bilgileri.

Tüm boyutların kaynağı, seçilen 1254 × 1254 px İris Moru PNG çizimidir.
